# Kurucu Visuals Portfolio

Portfolio and service website for photographer and videographer Arda Kurucu.

[View the live site](https://www.ardakurucu.com)

I built the site as a custom static website for Kurucu Visuals. It includes responsive photo galleries, video work, service information, equipment details, contact and reservation sections, and mobile navigation.

## Stack

- HTML
- CSS
- JavaScript
- GitHub Pages
- custom domain through `CNAME`

## Run locally

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Main pages

- `index.html`: home, services, pricing, equipment, and contact
- `portre.html`: portrait work
- `etkinlik.html`: event and motion work
- `sinema.html`: cinema work
- `videography.html`: video work
- `creative.html`: creative portfolio
